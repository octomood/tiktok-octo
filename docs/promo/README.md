# Промо TikTok octo — 15 секунд, 1080×1920

Два вертикальных ролика в одном монохромном языке Material 3, с синтезированным
звуком и финалом на Telegram-канал `t.me/tiktok_octo` с QR-кодом:

- **`tiktok-octo-promo-15s.mp4`** — «первый мод на твой комп»: окно, лента,
  мини-плеер поверх рабочего чата. Обложка `poster.png`.
- **`tiktok-octo-plugins-15s.mp4`** — система плагинов: менеджер, установка,
  песочница и разрешения. Обложка `poster-plugins.png`.
- **`cover-16x9.png`** — обложка 16:9 для Telegram-канала: 12 языков
  интерфейса и список обновлений. Есть версия 1280×720.

Оба — H.264 High, 1080×1920, 30 к/с, 15.0 с, AAC 192 кбит/с 48 кГц,
≈ −16.3 LUFS, около 3.4 МБ.

```
docs/promo/
  scene.html           сцена ролика о моде (render(t), без CSS-переходов)
  plugins.html         сцена ролика о плагинах

  audio.py             синтез звука (синусы, фильтрованный шум, свёрточный реверб)
  cover-16x9.html      обложка 16:9 (1920×1080)
```

## Сборка

```bash
bash docs/promo/build.sh          # ролик о моде
bash docs/promo/build-plugins.sh  # ролик о плагинах
bash docs/promo/build-cover.sh    # обложка 16:9
```

Нужны `ffmpeg`, `python3` с `numpy` и `scipy`, `node` и установленный
Chromium из Playwright (`npx playwright install chromium`). Если в кеше
лежит другая версия Chromium, `render.mjs` возьмёт её сам; можно задать
`CHROME_PATH`. Промежуточные кадры складываются в `build/` и `build-plugins/`
(в git не идут).

## Ролик о плагинах

| Время       | Кадр                                                                 |
| ----------- | -------------------------------------------------------------------- |
| 0.0 – 2.0   | Логотип влетает с пружиной, подпись «теперь с плагинами»             |
| 2.0 – 5.2   | Белый стикер: **«ПЛАГИНЫ для TikTok octo»**, метка «новое», 0.5      |
| 5.2 – 8.5   | Менеджер плагинов: две карточки, «проверен», переключатель включается |
| 8.4 – 11.8  | Диалог установки: разрешения, риск, проверка кода, SHA-256           |
| 11.8 – 15.0 | `t.me/tiktok_octo` + QR, «плагины — в Telegram», платформы           |

Факты в кадре — из реальной системы: `hello-octo` и `octo-test` из
`plugins/examples`, разрешения `page:css` и `shortcuts`, риск «средний», проверки кода,
SHA-256 и состава пакета — из диалога установки. Менеджер и диалог нарисованы по мотивам
`src/renderer/plugins.html`, а не выдуманы.

## Обложка 16:9

`cover-16x9.png` (1920×1080) и `cover-16x9-1280.png` (1280×720) — для
Telegram-канала. Слева — «12 языков» и сетка всех языков из
`src/main/language-catalog.js` (11 новых + русский). Справа — только то, что
действительно ново в этом обновлении: язык сайта, стикеры в чате, отправка
стикера как фото и тёмная тема везде. Ниже — золотая плашка «Плагины · уже в
0.5»: система плагинов вышла раньше, поэтому она выделена, но не выдаётся за
новинку. `t.me/tiktok_octo` — белой кнопкой в шапке.

Обложка собирается тем же `render.mjs` (Playwright + Chromium), только
с окном 1920×1080 и без кадров: `bash docs/promo/build-cover.sh`.

## Почему так сделано

- **Кадры, а не скринкаст.** Сцена рисует состояние по `t` (0…15 с).
  Playwright делает 450 снимков, ffmpeg собирает их в 30 к/с — звук попадает
  в кадр с точностью до одного кадра.
- **Настоящий интерфейс.** Полоса заголовка, менеджер плагинов и диалог
  установки повторяют классы и иконки из `src/renderer`; метрики увеличены
  для телефона, палитра переведена в монохром.
- **Логотип из jpg.** У `tiktok-octo.jpg` чёрный фон, поэтому яркость
  переведена в альфу: стекло живёт в кадре без «квадрата» и складывается
  с фоном, виньеткой и зерном.
- **Звук без генеративной музыки.** `audio.py` собирает всё вручную.
  Фоли: удар стикера (бум + шлепок), маримба-риф, щелчки клавиш, клик
  переключателя, «поп» уведомления, стеклянные пинг-понги. Фоновая музыка —
  96 BPM, Am9 – Fmaj7 – Cmaj7 – G6: электропиано на FM, мягкий бас,
  бочка, шейкер и римшот, с дакингом под фоли. Реверберация — свёртка
  с синтезированным импульсом комнаты. Ни одного сэмпла и ни одной
  сгенерированной дорожки: только синтез.
- **Монохром.** `#0a0a0c`…`#f2f2f4`, зерно 12 к/с и мягкая виньетка.
