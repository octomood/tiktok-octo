# Промо TikTok octo — 1080×1920

Вертикальные ролики в одном монохромном языке Material 3, с синтезированным
звуком и финалом на Telegram-канал `t.me/tiktok_octo` с QR-кодом. Исключение —
плакатная реклама «color drop» в розовом на тёмном:

- **`tiktok-octo-promo-15s.mp4`** — «первый мод на твой комп»: окно, лента,
  мини-плеер поверх рабочего чата. Обложка `poster.png`.
- **`tiktok-octo-plugins-15s.mp4`** — система плагинов: менеджер, установка,
  песочница и разрешения. Обложка `poster-plugins.png`.
- **`tiktok-octo-ad-5s.mp4`** — 5-секундная реклама с озвучкой для вставки
  среди видео: «Первый мод TikTok для компа», финал — `t.me/tiktok_octo`.
- **`tiktok-octo-meme-24s.mp4`** — мемная реклама на 24 секунды: 47 вкладок,
  «работаю» с PiP и CTA. Обложка `meme-24s.png`.
- **`tiktok-octo-plugins-meme-24s.mp4`** — мемная реклама плагинов: установка
  файла, песочница, разрешения и свой плагин. Обложка `plugins-meme-24s.png`.
- **`tiktok-octo-night-20s.mp4`** — музыкальный ролик «одно видео»: ночной
  марафон с 23:58 до 04:00, таймер сна и будильник. Обложка `night-20s.png`.
- **`tiktok-octo-matrix-10s.mp4`** — заставка «dot matrix»: логотип собирается
  из светодиодных точек, панель гаснет, финал с QR. Обложка `matrix-10s.png`.
- **`tiktok-octo-logo-6s.mp4`** — квадратный анимированный логотип 1080×1080:
  только нота TikTok из светодиодных точек, без подписи и QR. Обложка
  `logo-6s.png`.
- **`tiktok-octo-drop-10s.mp4`** — плакатная реклама «color drop»: розовый
  #ED2161 на тёмном #101409, тяжёлый шрифт, слово «octo», плашки цветов,
  звезда и финал с QR. Обложка `drop-10s.png`.
- **`tiktok-octo-1.0-60s.mp4`** — минутный релизный ролик 1.0: восемь глав
  с главными изменениями из плана до v1.0.0.
- **`cover-1.0-16x9.png`** — общая картинка 1.0 для Telegram-канала:
  десять глав и 40 главных изменений. Есть версия 1280×720.
- **`cover-16x9.png`** — обложка 16:9 про 12 языков и интерфейс. Есть версия
  1280×720.
- **`news-1.1-16x9.png`** — картинка 16:9 «Что нового в 1.1.0» для поста
  в Telegram. Есть версия 1280×720.

15-секундные ролики — H.264 High, 1080×1920, 30 к/с, 15.0 с, AAC 192 кбит/с
48 кГц, ≈ −16.3 LUFS, около 3.4 МБ.

## Сборка

```bash
bash docs/promo/build.sh          # ролик о моде
bash docs/promo/build-plugins.sh  # ролик о плагинах
bash docs/promo/build-cover.sh    # обложка 16:9
bash docs/promo/build-news.sh     # картинка «Что нового» 16:9
bash docs/promo/build-ad.sh       # 5-секундная реклама
bash docs/promo/build-release.sh  # минутный ролик 1.0
bash docs/promo/build-meme.sh     # мемная реклама 24 с
bash docs/promo/build-meme-plugins.sh  # мемная реклама плагинов 24 с
bash docs/promo/build-night.sh    # музыкальный ролик «одно видео» 20 с
bash docs/promo/build-matrix.sh   # заставка «dot matrix» 10 с
bash docs/promo/build-logo.sh     # квадратный логотип 6 с
bash docs/promo/build-drop.sh     # плакатная реклама «color drop» 10 с
python3 docs/promo/night-feed.py  # перегенерировать кадры фида (если менялись)
```

Нужны `ffmpeg`, `python3` с `numpy` и `scipy`, `node` и установленный
Chromium из Playwright (`npx playwright install chromium`). Если в кеше
лежит другая версия Chromium, `render.mjs` возьмёт её сам; можно задать
`CHROME_PATH`. Промежуточные кадры складываются в `build/`, `build-plugins/`,
`build-meme/` и `build-drop/` (в git не идут).

## Мемная реклама 24 секунды

`tiktok-octo-meme-24s.mp4` — 1080×1920, 30 к/с, ровно 24.0 с, −13.5 LUFS.
Это не парадный ролик, а лента: быстрые склейки, крупные подписи, эмодзи,
штампы и знакомые всем ситуации.

| Время       | Кадр |
| ----------- | ---- |
| 0.0 – 2.6   | POV: «ты открыл TikTok в браузере, чтобы посмотреть ОДНО ВИДЕО» |
| 2.6 – 6.2   | 47 вкладок, «Загружаем 8-е видео», «Страница не отвечает», 97 °C |
| 6.2 – 9.0   | Стикер «МОД НА ТВОЙ КОМП» и записка «не для Minecraft, извини» |
| 9.0 – 12.4  | Одно окно, ноль вкладок, кнопка «поверх всех» и PiP |
| 12.4 – 16.1 | «РАБОТАЮ.» — чат «ты дома?» и видео в PiP над отчётом |
| 16.1 – 19.2 | Три плюшки: J K L, пропуск рекламы, GIF за 3 секунды |
| 19.2 – 21.3 | «Без браузера. Без вкладок. Без „скинь ссылку“» и комментарий про Linux |
| 21.3 – 24.0 | «Скачай. Потом спасибо» + QR на `t.me/tiktok_octo` |

Шутки не выдумывают функций: 47 вкладок — это браузер, «Страница не
отвечает» — диалог Chromium, «работаю» — PiP над документом, комментарий —
ответ про Linux, а три плюшки взяты из приложения. Мемный слой — только
подача: жёлтый маркер, эмодзи, штампы, тряска и монтаж.

Звук собран в `meme-audio.py`: 120 BPM, пиццикато Am–F–C–G, деревянный блок,
бочка и клэп. Мемные фоли — vine boom, скрэтч, «вентилятор взлетает»,
грустный тромбон, щелчки сообщений и финальный аккорд. Ни одного сэмпла.
Рендер — тем же `render.mjs`, только с `--scene meme.html`; кадры лежат
в `build-meme/` и в git не идут. QR на финальном кадре проверен `zbarimg`
по готовому mp4.

## «Одно видео» — музыкальный ролик 20 секунд

`tiktok-octo-night-20s.mp4` — 1080×1920, 30 к/с, ровно 20.0 с, −14.6 LUFS.
История в десяти тактах 120 BPM: от «посмотрю одно видео» до будильника
в четыре утра. Без голоса — всё держат музыка, часы, счётчик и мемные паузы.

| Время       | Кадр |
| ----------- | ---- |
| 0.0 – 2.0   | 23:58, «посмотрю ОДНО видео» |
| 2.0 – 4.0   | 00:12, «ещё одно», видео: 7 |
| 4.0 – 6.0   | 00:40, «ещё одно», видео: 23 |
| 6.0 – 8.0   | 01:20, реклама? «Пропуск», реклама: 0 |
| 8.0 – 10.0  | 02:10, GIF за 3 секунды, «готово» |
| 10.0 – 12.0 | 03:00, таймер сна на 15 минут |
| 12.0 – 14.0 | 03:01, «ЕЩЁ ОДНО» и vine boom |
| 14.0 – 16.0 | 03:59, статистика: 4 ч 12 мин и грустный тромбон |
| 16.0 – 18.0 | 04:00, будильник и «ладно, ещё одно» |
| 18.0 – 20.0 | «Спи. Завтра лента», `t.me/tiktok_octo` |

Внутри окна — не статичная картинка: `night-feed.py` рисует 6-секундный
луп (144 кадра, 24 к/с, 720×1280) со стеклянным логотипом, светом и

рендер остаётся детерминированным. GIF-превью листает те же кадры на 12 к/с.
Полоса просмотра в фиде тоже идёт от `t`.

Показаны реальные вещи: пропуск рекламы, GIF 3–10 с, таймер сна 15/30/60,
статистика просмотра. Шутка не выдумывает функций: в 03:00 таймер включён,
а в 03:01 всё равно «ещё одно». Звук — `night-audio.py`: Rhodes, мягкая
бочка, шейкер, бас, тиканье часов, будильник и финальный аккорд; ни одного
сэмпла. Постер — кадр 12.6, обложка `night-20s.png`.

## Заставка «dot matrix» 10 секунд

`tiktok-octo-matrix-10s.mp4` — 1080×1920, 30 к/с, ровно 10.0 с, −14.3 LUFS,
пик −1.4 dBFS, около 1.9 МБ. Подходит отдельным роликом и концовкой для
монтажа: логотип собирается из точек, панель гаснет, на её месте появляется
QR.

| Время       | Кадр |
| ----------- | ---- |
| 0.0 – 0.36  | сетка точек включается |
| 0.36 – 2.05 | логотип печатается диагональной развёрткой |
| 2.05 – 3.14 | сборка, «TikTok octo» и «без браузера и вкладок» |
| 3.14 – 3.40 | глитч строк и хроматическая кайма |
| 3.40 – 4.40 | райзер и снейр-ролл перед выключением |
| 4.40 – 5.96 | волна гасит панель, тон ползёт вниз |
| 5.96 – 10.0 | «Скачивай в Telegram», QR, `t.me/tiktok_octo`, платформы |

Логотип рисует `matrix.html` (квадрат 1080×1080, 6 с), вертикальная обёртка
`matrix-v.html` берёт его в iframe, добавляет подписи и финал и считает всё
от общего `t`. Края квадрата растворяются маской, поэтому панель не читается
как вставленная картинка. Звук — `matrix-audio.py`: тики печати идут вместе
с фронтом развёртки, на замке логотипа колокольчики, дальше глитч, райзер,
сползающий тон выключения и импакт на финале; ни одного сэмпла. Постер —
кадр 3.0, `matrix-10s.png`.

| 0.9 – 1.5   | слово «octo» бьёт в кадр и оседает |

## Мемная реклама плагинов 24 секунды

`tiktok-octo-plugins-meme-24s.mp4` — 1080×1920, 30 к/с, ровно 24.0 с, −14.5 LUFS.
Тот же мемный монтаж, но про систему плагинов: файл вместо установщика,
песочница, разрешения и собственный плагин на 20 строк.

| Время       | Кадр |
| ----------- | ---- |
| 0.0 – 2.6   | POV: «тебе мало стандартного TikTok? ты хочешь СВОЮ КНОПКУ» |
| 2.6 – 6.2   | `app.octo.gradient-frame`: установка из файла, разрешения, проверки |
| 6.2 – 9.0   | Менеджер: три карточки, тумблеры и выключение без перезапуска |
| 9.0 – 12.4  | Песочница: `require('fs')`, `child_process`, cookies и `window.octo` |
| 12.4 – 16.1 | Разрешения: `page:css`, `shortcuts`, `network` — до установки |
| 16.1 – 19.2 | Свой плагин: `octo.commands.add()`, AST-аудит, hot reload, 3 падения |
| 19.2 – 21.3 | Примеры: «Градиентная обводка», «Полка» и «твой плагин здесь» |
| 21.3 – 24.0 | QR на `t.me/octo_plugins`, «Ставь. Или пиши свой» |

Факты сверены с `docs/plugins/README.md` и `src/main/plugins/permissions.js`:
риск `page:css` — средний, `network` — высокий; `octo-test` — `page:css`;
`require`, `child_process` и cookies недоступны; `window.octo` работает только
в рамках разрешений. Встроенного каталога и автообновлений в менеджере нет,
поэтому в ролике нет «каталога в приложении» — только скачивание из
Telegram-канала. Пакеты в `plugins/packages` без отдельной подписи, поэтому в
кадре менеджера стоит «без подписи», а не «проверен». QR проверен `zbarimg`
по кадру из готового mp4.

Звук — `meme-plugins-audio.py`: 120 BPM, Dm–Bb–F–C, пиццикато и 8-битный лид,
boom, скрэтч, низкие «нельзя» песочницы, щелчки установки и hot reload.

## Почему так сделано

- **Кадры, а не скринкаст.** Сцена рисует состояние по `t` (0…15 с).
  Playwright делает 450 снимков, ffmpeg собирает их в 30 к/с — звук попадает
  в кадр с точностью до одного кадра.
- **Настоящий интерфейс.** Полоса заголовка, менеджер плагинов и диалог
  установки повторяют классы и иконки из `src/renderer`; метрики увеличены
  для телефона, палитра переведена в монохром.
- **Логотип из jpg.** У `tiktok-octo.jpg` чёрный фон, поэтому яркость
  переведена в альфу: стекло живёт в кадре без «квадрата» и складывается
  с фоном, виньеткой и зерном.
- **Звук без генеративной музыки.** `audio.py` собирает всё вручную.
  Фоли: удар стикера (бум + шлепок), маримба-риф, щелчки клавиш, клик
  переключателя, «поп» уведомления, стеклянные пинг-понги. Фоновая музыка —
  96 BPM, Am9 – Fmaj7 – Cmaj7 – G6: электропиано на FM, мягкий бас,
  бочка, шейкер и римшот, с дакингом под фоли. Реверберация — свёртка
  с синтезированным импульсом комнаты. Ни одного сэмпла и ни одной
  сгенерированной дорожки: только синтез.
- **Монохром.** `#0a0a0c`…`#f2f2f4`, зерно 12 к/с и мягкая виньетка.

## Порядок работы для агента

1. Возьмите ближайший ролик за основу: `scene.html`/`meme.html` для
   HTML + Chromium, `ad-frames.py`/`release-anim.py` для PIL. Сцена считает
   состояние из `t`; CSS-переходы и анимации не используются.
2. Проверьте ключевые кадры:
   `node render.mjs --scene meme.html --still 3.4 --dsf 1 --out /tmp/promo-stills`,
   затем посмотрите PNG. Отдельно проверьте первый кадр каждой сцены и все
   склейки.
3. Соберите звук и проверьте громкость:
   `python3 meme-audio.py build-meme/audio.wav`,
   `ffmpeg -i build-meme/audio.wav -af ebur128=peak=true -f null -`.
   Цель — около −14 LUFS, пик не выше −1 dBFS.
4. Полный рендер: `bash docs/promo/build-meme.sh` в фоне, лог в файл.
   Для 24 секунд при `--dsf 2` это около 5–7 минут и ~900 МБ кадров
   в `build-meme/`; для другой длины время и объём масштабируются.
   Перерендерить один диапазон: `node render.mjs --scene meme.html
   --start 6.2 --end 9 --out build-meme` (кадры вне диапазона не трогаются).
5. Проверьте готовый файл: `ffprobe` (длительность, кадры, звук), кадр из mp4
   и QR через `zbarimg`.
6. Обновите этот README. В `CHANGELOG.md` промо не попадает.

### Грабли

- `box-sizing: border-box` обязателен для карточек с фиксированной шириной и
  padding: иначе 820 px + 140 px padding вылезают за 1080.
- Крупный заголовок с `white-space: nowrap` легко выходит за кадр. Проверяйте
  still, а не только CSS.
- `show()` должен ставить `display: block`, а не `''`, если у `section` в CSS
  стоит `display: none`.
- На склейке контент должен появляться сразу. Если reveal начинается через
  0,1 с после смены сцены, в mp4 попадут чёрные кадры.
- Эмодзи рисует системный `Noto Color Emoji`; проверяйте, что они не квадраты.
- QR 400 px внутри 1080 читается, но проверять надо кадр из **готового** mp4.
- `-t <длительность> -shortest`: для 24 с при 30 к/с должно быть 720 кадров.
  Сверяйте `nb_frames` в `ffprobe`, а не доверяйте таймеру ffmpeg.
- Постер берите из финальных кадров (`--still` по нужному `t`), а не из
  промежуточной сцены «на глаз».
