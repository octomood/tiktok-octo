# Промо TikTok octo — 15 секунд, 1080×1920

Ролик для TikTok: монохромный, в языке Material 3, собран из настоящего
интерфейса приложения. Каждый кадр считается в Chromium как чистая функция
от времени, поэтому нет пропусков, дрожания и «плавающих» анимаций.

**Результат:** `tiktok-octo-promo-15s.mp4` — H.264 High, 1080×1920, 30 к/с,
15.0 с, AAC 192 кбит/с 48 кГц, ≈ −14 LUFS, 2.5 МБ. Обложка — `poster.png`.

```
docs/promo/
  scene.html        сцена и таймлайн (render(t), без CSS-переходов)
  render.mjs        покадровый рендер через Playwright → build/frames/*.png
  audio.py          синтез звука (синусы, фильтрованный шум, свёрточный реверб)
  build.sh          полная сборка: звук → кадры → H.264/AAC → постер
  tiktok-octo-promo-15s.mp4   результат
  poster.png        кадр-обложка 1080×1920
```

## Сборка

```bash
bash docs/promo/build.sh
```

Нужны `ffmpeg`, `python3` с `numpy` и `scipy`, `node` и установленный
Chromium из Playwright (`npx playwright install chromium`). Если в кеше
лежит другая версия Chromium, `render.mjs` возьмёт её сам; можно задать
`CHROME_PATH`. Промежуточные кадры складываются в `build/` (в git не идут).

## Почему так

- **Кадры, а не скринкаст.** `scene.html` рисует состояние по `t`
  (0…15 с). Playwright делает 450 снимков, ffmpeg собирает их в 30 к/с.
  Никаких пропущенных кадров и рассинхрона — звук попадает в кадр
  с точностью до одного кадра.
- **Настоящий интерфейс.** Полоса заголовка, поиск и мини-плеер — те же
  классы и иконки, что в `src/renderer`; для читаемости на телефоне
  метрики увеличены, палитра переведена в монохром. Знак — контурный
  осьминог из `build/icon.svg`, подписи — Inter и JetBrains Mono.
- **Звук без генеративной музыки.** `audio.py` собирает фоли вручную:
  маримба-щипки из негармонических синусов, деревянные «токи» на посадке
  карточек, стеклянные пинг-понги на счётчике совпадений, воздушные
  протяжки из шума с плавающей полосой и тёплый аккорд Am9 в финале.
  Реверберация — свёртка с синтезированным импульсом маленькой комнаты.
  Ни одного сэмпла и ни одной сгенерированной дорожки: только синтез.
- **Монохром.** Вся сцена живёт в серых тонах (`#0a0a0c`…`#f2f2f4`),
  поверх — зерно 12 к/с и мягкая виньетка, чтобы кадр не выглядел
  «стерильным».

## Таймлайн

| Время       | Кадр                                          |
| ----------- | --------------------------------------------- |
| 0.0 – 2.9   | Знак, вордмарк, расходящиеся круги            |
| 2.6 – 5.4   | Полоса заголовка собирается, горячие клавиши  |
| 5.5 – 8.4   | Поиск по странице: набор, счётчик 1/3 → 3/3   |
| 8.4 – 11.9  | Мини-плеер поверх «рабочего стола»            |
| 12.0 – 15.0 | Финальная плашка: платформы, репозиторий, MIT |
