# План до 1.0.0

Список фич из `Планы до v1.0.0` разложен по релизам: сначала то, что делает
приложение удобнее каждый день, затем крупные подсистемы (чат, библиотека,
плагины), в конце — интеграция с системой и полировка. Версии после 0.9.x
внутренние: номер меняется, когда блок готов целиком.

Правила для каждого блока те же, что и для обычной правки: `CHANGELOG.md`,
переводы во всех `src/main/locales/*.json`, Playwright-тест, `npm run lint`,
`npm test`, `prettier --check`, `npm run install:local`. Вопросы, которые
меняют публичное API плагинов, разрешения или данные пользователя, задаются
до реализации.

## 0.6.0 — Плеер и звук

Зависимостей нет, всё живёт в `player.js`, `pip.js` и `sleep-timer.js`.

- Усиление громкости до 200 % через Web Audio `GainNode`; выше 100 % работает
  только когда медиа доступно без CORS-ограничений, иначе громкость остаётся
  обычной и приложение честно об этом говорит.
- Выбор аудиовыхода через `setSinkId` (`AudioContext` для Web Audio-цепочки,
  сам `<video>` — без неё).
- Эквалайзер «речь»/«музыка» и моно-режим на той же цепочке.
- Скраб-бар и таймкод в PiP, кнопка «−10 секунд».
- Таймер сна: «до конца ролика», «стоп после N видео», плавное затухание и
  сохранение между запусками.

## 0.7.0 — Клавиатура

Готово.

- Редактор горячих клавиш: переназначение команд, подсветка конфликтов,
  профили «Стандартный», «Компактный» и «Свой».
- Клавиатурная лента: <kbd>J</kbd>/<kbd>L</kbd>, <kbd>K</kbd> и пробел, цифры
  в процентах, <kbd>S</kbd> — снимок кадра, <kbd>?</kbd> — раздел «Клавиши».
  Слушатель живёт в изолированном preload: ввод в полях не перехватывается,
  а страница не может отправлять эти команды.
- Автопауза по простою и `powerSaveBlocker`, пока идёт воспроизведение.
- «Открыть текущую страницу в браузере» — кнопка, палитра и хоткей.

## 0.7.1 — Картинка и лента

Готово.

- Субтитры по умолчанию, размер/фон/обводка без изменения настроек аккаунта.
- Настройка картинки: яркость, контраст, тёплый фильтр, «вписать» и
  «заполнить окно».
- Дата публикации видео в рекомендациях, когда сайт её показывает.
- QR-код текущего видео (локальная генерация, без внешних сервисов).
- Режим «только полоса»: название ролика, play/pause, громкость и PiP без сайта.

## 0.7.x — Уведомления и чат

Готово.

- Нативные уведомления о новых сообщениях по счётчику в заголовке, расписание
  «не беспокоить» и «не уведомлять в активном окне». Тип уведомления из
  заголовка не определяется — это честно описано в интерфейсе и README.
- Ширина и док чата: тянется мышью, запоминается; по умолчанию лента
  поджимается, тумблер возвращает вариант поверх ленты.
- Перетаскивание файлов в чат: drop на панель = отправить как фото; слушатель
  в изолированном preload, только для панели чата.
- Быстрые ответы: шаблоны в палитре, вставка в открытый диалог без отправки.

## 0.8.1 — Фокус, амбиент и архив

## 1.0.0b — Хуки ОС и полировка

Готово.

- Windows: кнопки play/pause, PiP, «Сообщения» и «Без звука» в превью панели
  задач; SMTC и метаданные — через media session Chromium.
- Плагины: разрешение `os:notify` и `octo.os.notify({ title, body })` с
  лимитами; типы, мок и документация обновлены.
- Финальная полировка: тесты панели ждут готовности titlebar, переводы и
  документация обновлены, сборка проверена.

Автозапуск и глобальные клавиши для плагинов в этот блок не входят: для них
нужно отдельное решение по разрешениям `os:autostart` и `os:hotkey`.
