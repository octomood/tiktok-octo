# Сайт TikTok octo

Статический лендинг проекта: монохромная дота-матрица, один экран на секцию.
Он не входит в сборку Electron и не связан с `src/`: это отдельная страница в
репозитории, чтобы её можно было открыть, показать и потом перенести на домен.

## Открыть

```bash
cd site && python3 -m http.server 8080
```

Затем `http://localhost:8080/` в браузере. Шрифты грузятся с Google Fonts,
поэтому без сети страница покажет системную подмену; всё остальное локальное.

## Файлы

| Файл          | Что это                                                                   |
| ------------- | ------------------------------------------------------------------------- |
| `index.html`  | вся страница: разметка, копия, CSS визуалов                               |
| `favicon.svg` | точечный знак для вкладки                                                 |
| `share.jpg`   | картинка для `og:image`                                                   |
| `assets/`     | рантайм-часть набора дизайн-системы (system, layout, motion, ui, moments) |

`assets/` — вендорная копия набора, которым собиралась страница. Правки страницы
делаются в `index.html`; файлы набора не переписываются.

## Решения

- **Тип страницы:** software. Секции: hero, панель «Функции» (`app-frame`),
  возможности (2×2), тихий режим (тёмная полоса), момент со словом-подсветкой,
  вопросы, финальный экран.
- **Монохром:** чернила `#15141c` на бумаге `#f3f1ea`, второй тон — `#e9e6dc`.
  Акцент равен чернилам, цвета в интерфейсе нет вовсе.
- **Шрифты:** Handjet (точечная гарнитура, ось `ELSH`) для заголовков и цифр,
  JetBrains Mono для текста. Оба с кириллицей.
- **Визуалы:** окно приложения, мини-плеер, загрузки, плагины и клавиши нарисованы
  живым HTML по реальному устройству приложения (полоса 44 px, панель «Функции»,
  шаблон имени файла, подпись Ed25519). Скриншоты TikTok не используются.
- **Движение:** вход героя, раздача момента `word-highlight` в секции
  `#statement`, ховеры набора. WebGL нет.
- **Знак:** разданный `ring`; фирменный стеклянный осьминог из `docs/banner.png`
  в SVG не переводился — его нужно получить у клиента, если он должен стоять в
  шапке.

## Проверки

Страница проверялась набором `design-taste-frontend` (скрипты вне репозитория,
Chrome — headless из кэша Playwright):

```bash
export CHROME_PATH=~/.cache/ms-playwright/chromium-1243/chrome-linux64/chrome
node <набор>/scripts/gate.mjs site/index.html
node <набор>/scripts/shoot.mjs --url site/index.html --w 1440 --out site/shots/1440.png --profile site/.taste-skill/chrome
```

`shots/` и `.taste-skill/` — сгенерированное, в коммит не идут.

## Что осталось за клиентом

- домен и канонический адрес (`<link rel="canonical">` закомментирован);
- почта для формы обратной связи (сейчас ссылки ведут в GitHub Issues);
- фирменный SVG-знак, если octo нужен вместо точечного кольца;
- настоящие скриншоты приложения, если захочется заменить нарисованные панели.
