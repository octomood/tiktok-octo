# Changelog

## 0.4.1

### Изменено

- Интерфейс приложения и текст сайта переведены на **Inter** (SIL OFL 1.1).
  Шрифт встроен в сборку: оболочка грузит его из `assets/fonts`, сайт получает
  те же файлы через косметическое правило «Современный шрифт на сайте»
  (включено по умолчанию, отключается в панели). Иконочные шрифты TikTok не
  затрагиваются — проверено на живой странице.

## 0.4.0

### Добавлено

- **Палитра команд** (`Ctrl+K`, меню и панель): поиск по всем действиям —
  навигация, поиск, косметика, плеер, таймер сна, загрузки, выход. Стрелки и
  Enter, `Esc` закрывает; на время показа `WebContentsView` скрывается.
- **Настройки плеера**: скорость по умолчанию (0.5/1/1.5/2×), «запускать без
  звука», повтор видео и пауза при потере фокуса/сворачивании. Применяются к
  каждому новому видео.
- **Снимок кадра** (`Ctrl+Shift+S`): PNG в «Изображения» и в буфер обмена.
- Скриншоты можно направлять в отдельный каталог через
  `OCTO_SCREENSHOT_DIR` (используется тестами).

### Исправлено

- Косметические JS-правила (промо, замена логотипа) больше не зависят от
  `did-stop-loading`: на бесконечно загружающейся ленте они вообще не
  применялись. Выполнение переведено на общий `page-eval` через CDP, без
  накопления слушателей и утечек.

## 0.3.0

### Добавлено

- **Логотип бренда на сайте**: знак TikTok заменяется на `tt-octo` — полный
  локап в шапке и развёрнутом рельсе, только знак приложения в свёрнутом.
  Косметическое правило «Логотип tt-octo вместо TikTok» (включено по умолчанию).
- **Менеджер загрузок**: очередь, прогресс, отмена, «показать в папке» и
  история текущей сессии в панели функций.
- **Таймер сна** на 15/30/60 минут с обратным отсчётом; по истечении ставит
  видео на паузу.
- **Автозапуск** (Linux — `.desktop` в `XDG_CONFIG_HOME/autostart`, macOS и
  Windows — штатный API) и **запуск свёрнутым в трей** (`--hidden`).
- **MPRIS для Linux**: «сейчас играет», play/pause, next/previous из
  GNOME/KDE/`playerctl`; метаданные читаются из текущего видео, с fallback на
  заголовок страницы.
- Новые разделы панели: «Загрузки», переключатели автозапуска и запуска в трее,
  таймер сна в «Воспроизведении».

## 0.2.0

### Добавлено

- Поиск по странице (`Ctrl+F`, `Ctrl+G`, `F3`) с числом совпадений.
- Контекстное меню контента: копирование/вставка, орфография, «открыть ссылку в
  браузере», «сохранить изображение», «найти на странице».
- Трей: показать/скрыть окно, звук, «поверх всех окон», PiP, «закрывать в трей».
- Бейдж непрочитанных из заголовка страницы (macOS и Unity-лончеры Linux).
- Прогресс скачивания в полосе заголовка.
- Восстановление последней страницы при запуске.
- Медиа-клавиши Play/Pause и Stop.
- Косметический слой: скрытие промо «Скачать приложение» и «Открыть в
  приложении», тёмные скроллбары, опциональное скрытие разделов «Трансляция» и
  «Мини-сериалы». Переключатели — в меню «Вид» и в трее, состояние хранится в
  `octo-state.json`.
- Боковая панель функций (`Ctrl+Shift+B`, кнопка в полосе заголовка, меню «Вид»
  и трей): категории «Страница», «Воспроизведение», «Косметика», «Приложение».
  Панель сдвигает сайт вправо, а не перекрывает его.
- Автообновление через `electron-updater` и GitHub Releases.
- Дымовой тест Playwright, ESLint, Prettier, CI на GitHub Actions.
- Сборка релизов на трёх платформах по тегу `v*`.

### Изменено

- `main.js` разложен на модули (`window`, `view`, `session`, `commands`,
  `shortcuts`, `menu`, `tray`, `find`, `hardening`, `store`, `updates`).
- `Ctrl+R` — обычное обновление, `Ctrl+Shift+R` — без кэша.
- Меню приложения доступно на всех платформах (на Linux/Windows — по `Alt`).

### Исправлено

- Ссылки на `facebook.com`/`x.com` больше не заменяют ленту: OAuth определяется
  по хосту **и** пути, а не только по хосту.
- Разрешения (камера, микрофон, уведомления) выдаются только origin'ам TikTok.
- OAuth-popup'ы не могут уйти на произвольный сайт или открыть новое окно.
- Серверные редиректы на внешние хосты перехватываются (`will-redirect`).
- Падение рендерера больше не вызывает бесконечную перезагрузку: backoff и
  лимит попыток.
- Состояние PiP подсвечивается на кнопке и синхронизируется при возврате фокуса.
- `.deb` снова собирается: в `package.json` указан email мейнтейнера, которого
  требует electron-builder.
