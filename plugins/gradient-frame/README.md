# Градиентная обводка

Переливающаяся рамка вокруг ролика в ленте или по краю окна TikTok Octo.
Всё оформление — CSS на странице; плагин не читает содержимое роликов, не
ходит в сеть и не просит ничего, кроме `page:css`.

## Что умеет

- **Два места.** Рамка вокруг карточки ролика (в ленте и на странице видео),
  по краю всего окна приложения или сразу в обоих местах.
- **Шесть палитр.** TikTok, неон, закат, океан, северное сияние и белый металл.
- **Свои цвета.** Три HEX-цвета, если готовых палитр мало.
- **Четыре режима.** Вращение градиента, перелив вдоль рамки, пульсация или
  статичная рамка.
- **Форма и сила.** Толщина, скругление, отступ от края, период анимации,
  свечение и прозрачность.
- **Уменьшение движения.** Если в системе включено уменьшение анимации, рамка
  остаётся на месте (настройку можно выключить).
- **Превью в менеджере.** Как косметический пак, обводку можно включить на
  20 секунд, чтобы посмотреть до установки или на выключенном плагине.

## Установка

Готовый пакет лежит в `plugins/packages/app.octo.gradient-frame-1.0.0.octoplugin`:

1. **Плагины → Установить из файла…**
2. Выберите пакет и подтвердите разрешение `page:css`.

Или соберите сами:

```bash
node scripts/pack-plugin.js plugins/gradient-frame --out plugins/packages
```

Для разработки положите папку в каталог dev-плагинов:

```bash
OCTO_PLUGIN_DEV_DIR=$PWD/plugins npm start
```

Настройки меняются в карточке плагина: **Плагины → Менеджер плагинов →
Установленные → Градиентная обводка → Настройки**.

## Настройки

| Настройка                   | Значение по умолчанию       | Что делает                             |
| :-------------------------- | :-------------------------- | :------------------------------------- |
| Показывать обводку          | включено                    | главный выключатель эффекта            |
| Где рисовать                | вокруг ролика               | ролик, край окна или оба места         |
| Палитра                     | TikTok                      | готовый набор цветов                   |
| Свой цвет 1/2/3             | бирюза, розовый, фиолетовый | цвета для палитры «Свои цвета»         |
| Анимация                    | вращение                    | вращение, перелив, пульсация или нет   |
| Толщина, px                 | 4                           | ширина рамки                           |
| Скругление, px              | 18                          | радиус углов                           |
| Отступ внутрь, px           | 0                           | сдвиг рамки от края                    |
| Период анимации, с          | 4                           | длительность одного цикла              |
| Свечение, px                | 12                          | цветной ореол вокруг рамки             |
| Прозрачность                | 0.9                         | сила эффекта                           |
| Уважать уменьшение движения | включено                    | не анимировать при системной настройке |

Цвета принимаются в HEX: `#25f4ee`, `#f2c`, `#11223344`. Неверное значение
заменяется стандартным, чтобы рамка не исчезла из-за опечатки.

## Разрешения

| Разрешение | Зачем                                      |
| :--------- | :----------------------------------------- |
| `page:css` | нарисовать и анимировать рамку на странице |

Плагин не использует `page:script`, сеть, хранилище и навигацию.

## Ограничения

- TikTok меняет разметку. Обводка ищет стабильные `data-e2e`-контейнеры
  (`recommend-list-item-container`, `browse-video`, `feed-item`, `feed-video`) и
  `article` с видео. Если сайт переименует их, рамка может пропасть до
  обновления плагина.
- Рамка рисуется внутри выбранного контейнера. Если сайт обрезает содержимое
  карточки, толстая рамка со свечением может быть частично скрыта — уменьшите
  толщину или отступ.
- Настройка «Уважать уменьшение движения» ориентируется на системную опцию
  `prefers-reduced-motion`.
