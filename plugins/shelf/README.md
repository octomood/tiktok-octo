# Полка

Закладки внутри TikTok octo: сохраните видео, профиль, звук или поиск и
вернитесь к ним позже. Всё лежит на устройстве — плагин не ходит в сеть и не
трогает аккаунт.

## Что умеет

- **Сохранить страницу** — панель функций, палитра команд или
  <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>L</kbd>. В закладку попадают заголовок,
  автор из адреса и дата.
- **Случайная страница** — «достать с полки» то, что давно отложили:
  <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>L</kbd> или строка в панели.
- **Ссылка из контекстного меню** — правый клик по ссылке в описании или
  комментарии → «Полка: сохранить ссылку».
- **Метка «На полке»** — маленький бейдж в углу, если открытая страница уже
  сохранена. Отключается в настройках плагина.
- **Список в палитре** — каждая закладка становится отдельной командой, так что
  открыть её можно через поиск команд.
- **Убрать и очистить** — текущая страница убирается одной командой, вся полка
  очищается после повторного подтверждения в течение 5 секунд.

Полка хранит последние 20 страниц по умолчанию (настраивается от 4 до 40).
Старые закладки удаляются автоматически, чтобы хранилище плагина не росло
бесконечно.

## Установка

Готовый пакет лежит в `plugins/packages/app.octo.shelf-1.0.0.octoplugin`:

1. **Плагины → Установить из файла…**
2. Выберите пакет и подтвердите разрешения.

Или соберите сами:

```bash
node scripts/pack-plugin.js plugins/shelf --out plugins/packages
```

Для разработки положите папку в каталог dev-плагинов и запустите приложение:

```bash
OCTO_PLUGIN_DEV_DIR=$PWD/plugins npm start
```

## Разрешения

| Разрешение    | Зачем                                                   |
| :------------ | :------------------------------------------------------ |
| `page:script` | прочитать адрес, заголовок и описание открытой страницы |
| `page:css`    | показать метку «На полке»                               |
| `navigation`  | открыть сохранённую страницу внутри приложения          |
| `shortcuts`   | две горячие клавиши для сохранения и случайной закладки |

Данные хранятся только в `octo.storage` плагина. Сеть не используется,
секреты и cookies не читаются.

## Ограничения

- Открывать можно только страницы TikTok: `octo.navigate` не пускает внешние
  сайты. Ссылка на другой сайт сохранится, но при открытии плагин честно
  скажет, что переход запрещён.
- Заголовок берётся из страницы в момент сохранения. Если TikTok ещё не
  догрузил описание, останется только автор из адреса.
- Полка общая для профиля приложения и удаляется вместе с плагином.
