# Octo Test

Самый простой плагин для проверки системы. Нужен только `page:css`.

## Что делает

- Обводит ролики и видео розовой рамкой.
- Рисует розовую рамку по краю окна — её видно даже если TikTok поменял разметку.
- Показывает сверху бейдж **OCTO TEST OK**.
- Добавляет команду **«Тест: привет»** в палитру и меню.
- Добавляет строку **«Тест: текущее время»** в панель функций.

## Как проверить

1. Соберите пакет командой из раздела «Сборка» (или запустите папку через
   `OCTO_PLUGIN_DEV_DIR`).
2. Откройте **Плагины → Установить из файла…** и выберите собранный архив
   `dist/app.octo.test-basic-1.0.1.octoplugin`.
3. Подтвердите установку — плагин просит только CSS.
4. Откройте ленту: должна появиться розовая рамка и бейдж **OCTO TEST OK**.
5. Откройте панель функций → **Плагины** → нажмите **«Тест: текущее время»**.
6. Нажмите **<kbd>Ctrl</kbd>+<kbd>K</kbd>**, введите `Тест: привет` и выполните.
7. Выключите плагин в панели или менеджере — рамка и бейдж исчезнут.

Если включён строгий режим «только подписанные плагины», тестовый плагин
неподписанный: разрешите неподписанные на время проверки или запустите его
через `OCTO_PLUGIN_DEV_DIR`.

## Сборка

```bash
node scripts/pack-plugin.js plugins/examples/octo-test --out dist
```
