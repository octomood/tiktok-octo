# Доверенные ключи плагинов

Публичные ключи Ed25519 (`*.pem`, SubjectPublicKeyInfo), которым доверяет
приложение. Пакет, подписанный одним из них, показывается как
«официальный». Пустая папка — подписей нет, все плагины неподписанные.

- Новый ключ: `node scripts/plugin-keygen.js --trust` — создаёт пару в
  `.octo-keys/` и кладёт сюда `octo-<keyId>.pem`.
- Приватный ключ сюда не кладут никогда: приложение его пропустит, а
  `npm run plugin:verify` в CI упадёт.
- Ротация: добавьте новый ключ рядом со старым, выпустите приложение, начните
  подписывать новым, и только потом удалите старый файл.
